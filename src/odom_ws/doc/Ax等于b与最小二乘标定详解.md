# `Ax = b` 与最小二乘里程计标定详解

> 对应工程：`src/calib_odom`  
> 对应实现：`Odom_Calib::Add_Data()` 与 `Odom_Calib::Solve()`  
> 目标：理解如何由多组“里程计相对运动”和“激光扫描匹配相对运动”，求出一个 `3×3` 的里程计校正矩阵。

---

## 1. 这份作业究竟要解决什么问题

机器人在相邻两个时刻之间运动一次时，可以通过两种方式估计这段运动：

1. **轮式里程计**：由编码器等传感器推算；连续、短期平滑，但会受打滑、轮径误差等影响；
2. **激光扫描匹配**：由 PI-ICP / CSM 对相邻两帧激光进行匹配；可作为另一种相对运动观测。

对第 `k` 个有效帧对，记：

```text
odomₖ = [ox, oy, oθ]ᵀ
scanₖ = [sx, sy, sθ]ᵀ
```

其中：

```text
ox：里程计认为机器人向前的位移
oy：里程计认为机器人向左的位移
oθ：里程计认为机器人的偏航角变化（rad）

sx：激光匹配认为机器人向前的位移
sy：激光匹配认为机器人向左的位移
sθ：激光匹配认为机器人的偏航角变化（rad）
```

两种增量都表达在**上一帧机器人局部坐标系**中。作业希望学习一个校正矩阵 `M`，使得：

```text
scanₖ ≈ M · odomₖ
```

之后，对新的里程计增量使用：

```text
correct_inc = M · odom_inc
```

得到校正后的增量，并将它们重新积分成校正路径。

---

## 2. 矩阵模型：`scan ≈ M · odom`

将未知校正矩阵写为：

```text
M = [m00  m01  m02
     m10  m11  m12
     m20  m21  m22]
```

某一组观测写成：

```text
odom = [ox, oy, oθ]ᵀ
scan = [sx, sy, sθ]ᵀ
```

则：

```text
[sx]   [m00  m01  m02] [ox]
[sy] ≈ [m10  m11  m12] [oy]
[sθ]   [m20  m21  m22] [oθ]
```

将矩阵乘法展开，得到三条标量方程：

```text
sx ≈ m00·ox + m01·oy + m02·oθ
sy ≈ m10·ox + m11·oy + m12·oθ
sθ ≈ m20·ox + m21·oy + m22·oθ
```

这三条式子中，已知量是：

```text
ox、oy、oθ、sx、sy、sθ
```

未知量是：

```text
m00、m01、m02、m10、m11、m12、m20、m21、m22
```

即一共 9 个未知数。

---

## 3. 为什么要把矩阵 `M` 展开为向量 `x`

常见线性方程组的形式是：

```text
A x = b
```

这里 `x` 通常是“所有未知量排成的一列”。因此将矩阵 `M` 按行展开：

```text
x = [m00, m01, m02, m10, m11, m12, m20, m21, m22]ᵀ
```

也可竖着写成：

```text
x = [m00]
    [m01]
    [m02]
    [m10]
    [m11]
    [m12]
    [m20]
    [m21]
    [m22]
```

注意：这里的 `x` **不是位置坐标**，而是待估计的 9 个标定参数。

后续 `Solve()` 求得这个长度为 9 的向量后，再把它恢复为原来的 `3×3` 矩阵 `M`。

---

## 4. 单个样本如何写成 `Aₖx = bₖ`

将第 2 节的三条标量方程重新整理，让未知量的排列顺序与 `x` 一致：

```text
sx ≈ [ox, oy, oθ, 0,  0,  0,  0,  0,  0] · x
sy ≈ [0,  0,  0,  ox, oy, oθ, 0,  0,  0] · x
sθ ≈ [0,  0,  0,  0,  0,  0,  ox, oy, oθ] · x
```

将三行合并：

```text
Aₖ x = bₖ
```

其中：

```text
Aₖ = [ox  oy  oθ   0   0   0   0   0   0
       0   0   0  ox  oy  oθ   0   0   0
       0   0   0   0   0   0  ox  oy  oθ]

bₖ = [sx, sy, sθ]ᵀ
```

尺寸为：

```text
Aₖ：3 × 9
x ：9 × 1
bₖ：3 × 1
```

检查矩阵乘法的尺寸：

```text
(3 × 9) · (9 × 1) = (3 × 1)
```

结果正好和 `bₖ` 一样是三维向量。

---

## 5. `A`、`x`、`b` 分别表达什么

可以用下面的表格记忆：

| 符号 | 在本作业中的含义 | 是否已知 |
|---|---|---:|
| `A` | 由每组里程计增量构造的观测矩阵 | 是 |
| `x` | 校正矩阵 `M` 的 9 个元素组成的列向量 | 否，需要求解 |
| `b` | 每组激光 PI-ICP 相对位姿按顺序堆叠的观测向量 | 是 |

一句话概括：

```text
A：已知的里程计数据怎样约束校正参数
x：待求的 9 个校正参数
b：希望拟合到的激光扫描匹配结果
```

程序中的成员变量为：

```cpp
Eigen::MatrixXd A;
Eigen::VectorXd b;
```

其中 `b` 是动态长度列向量。它依次存储每一组激光观测：

```text
b = [sx₀, sy₀, sθ₀,
     sx₁, sy₁, sθ₁,
     sx₂, sy₂, sθ₂,
     ...]ᵀ
```

对于第 `k` 组样本：

```text
b[3k]     = sxₖ
b[3k + 1] = syₖ
b[3k + 2] = sθₖ
```

---

## 6. 多个样本：从 `Aₖx=bₖ` 堆叠成 `Ax=b`

单个样本只提供 3 条方程，但我们需要估计 9 个未知数。因此需要积累很多组有效运动样本。

假设一共收集 `N` 组观测：

```text
A₀x ≈ b₀
A₁x ≈ b₁
A₂x ≈ b₂
...
Aₙ₋₁x ≈ bₙ₋₁
```

将它们向下堆叠：

```text
A = [A₀
     A₁
     A₂
     ...
     Aₙ₋₁]

b = [b₀
     b₁
     b₂
     ...
     bₙ₋₁]
```

得到：

```text
A x ≈ b
```

整体矩阵尺寸是：

```text
A：3N × 9
x：9 × 1
b：3N × 1
```

例如本工程配置：

```cpp
Odom_calib.Set_data_len(12000);
```

最大使用 `12000` 组样本，因此：

```text
A：36000 × 9
x：    9 × 1
b：36000 × 1
```

此时有远多于未知数的方程：

```text
3N > 9
```

这样的系统称为**超定方程组**（overdetermined system）。

---

## 7. 为什么写作 `Ax ≈ b`，却称作解 `Ax=b`

数学教材和工程中，经常将这一类问题简称为“解 `Ax=b`”。但在真实机器人数据中，严格相等通常不可能成立：

```text
轮编码器量化与累计误差
轮胎打滑
轮径、轮距的模型误差
激光测距噪声
PI-ICP 匹配误差
时间戳和同步误差
机器人在地面上的真实运动偏离简化模型
```

因此，真实关系通常是：

```text
A x ≈ b
```

定义残差（residual）：

```text
r = A x - b
```

最小二乘法希望找到一个 `x`，让所有方程整体尽可能接近：

```text
min ||A x - b||²
```

其中：

```text
||A x - b||²
```

是所有残差平方后的总和。它越小，说明校正后的里程计增量整体越接近激光匹配增量。

## 8. 一个数值样本示例

假设机器人从上一帧到当前帧时，里程计估计：

```text
odom = [0.10, 0.00, 0.05]ᵀ
```

即：

```text
向前 0.10 m
向左 0.00 m
逆时针转 0.05 rad
```

激光扫描匹配结果为：

```text
scan = [0.098, 0.001, 0.048]ᵀ
```

那么这一组样本贡献的方程为：

```text
[0.10  0.00  0.05   0     0     0     0     0     0] x   [0.098]
[  0     0     0   0.10  0.00  0.05   0     0     0]   [0.001]
[  0     0     0     0     0     0   0.10  0.00  0.05]   [0.048]
```

它单独无法确定 9 个参数，但与后续大量不同运动方式的样本组合后，可以共同确定一个最合适的 `M`。

## 9. `Add_Data()` 如何对应数学公式

工程中，`Add_Data()` 的关键实现是：

```cpp
const int row = now_len * 3;
A.block<1, 3>(row, 0) = Odom.transpose();
A.block<1, 3>(row + 1, 3) = Odom.transpose();
A.block<1, 3>(row + 2, 6) = Odom.transpose();
b.segment<3>(row) = scan;
```

假设当前这是第 `k = now_len` 组样本，则：

| 代码 | 数学含义 |
|---|---|
| `row = 3k` | 本组样本在总方程中的起始行 |
| `A.block<1,3>(3k,0)` | `A` 第 `3k` 行第 `0~2` 列填入 `[ox, oy, oθ]` |
| `A.block<1,3>(3k+1,3)` | `A` 第 `3k+1` 行第 `3~5` 列填入 `[ox, oy, oθ]` |
| `A.block<1,3>(3k+2,6)` | `A` 第 `3k+2` 行第 `6~8` 列填入 `[ox, oy, oθ]` |
| `b.segment<3>(3k)` | 写入 `[sx, sy, sθ]ᵀ` |

`A` 在初始化阶段已经通过 `A.setZero()` 清零，所以未写入的位置保持为零。

写入成功后再执行：

```cpp
++now_len;
```

这样下一组样本从紧随其后的 3 行开始写入，也不会覆盖当前数据。

## 10. `Solve()` 怎样从 `x` 还原校正矩阵 `M`

`Solve()` 先用当前已有的有效样本行构建实际参与求解的方程：

```cpp
const Eigen::Index rows = static_cast<Eigen::Index>(now_len) * 3;
const Eigen::MatrixXd observations = A.topRows(rows);
```

然后求解最小二乘问题：

```cpp
Eigen::CompleteOrthogonalDecomposition<Eigen::MatrixXd> decomposition(observations);
const Eigen::VectorXd solution = decomposition.solve(b.head(rows));
```

求出的 `solution` 就是：

```text
solution = [m00, m01, m02, m10, m11, m12, m20, m21, m22]ᵀ
```

按第 3 节的约定，按行填回矩阵：

```cpp
correct_matrix.row(0) = solution.segment<3>(0).transpose();
correct_matrix.row(1) = solution.segment<3>(3).transpose();
correct_matrix.row(2) = solution.segment<3>(6).transpose();
```

最终得到：

```text
M = [x₀  x₁  x₂
     x₃  x₄  x₅
     x₆  x₇  x₈]
```

这个 `M` 随后被用于：

```text
correct_inc = M · odom_inc
```

并通过逐帧积分形成 `/calib_path_pub_`。

## 11. 为什么使用正交分解，而不是显式求逆

理论上，当 `AᵀA` 可逆时，最小二乘问题可写成：

```text
x = (AᵀA)⁻¹Aᵀb
```

但实际代码不应直接这么做。原因是：

```text
形成 AᵀA 会放大矩阵的条件数；
显式求逆会进一步放大浮点数误差；
里程计数据很可能存在尺度差异、近共线或重复运动。
```

因此程序使用 Eigen 的：

```text
CompleteOrthogonalDecomposition
```

它适合求线性最小二乘解，也能给出矩阵秩信息，数值稳定性优于手动计算正规方程的显式逆。

## 12. 为什么必须检查矩阵秩 `rank(A) = 9`

要估计的参数数量是 9，因此希望观测矩阵具有完整列秩：

```text
rank(A) = 9
```

如果：

```text
rank(A) < 9
```

表示采集的运动样本不能独立约束全部 9 个参数，校正矩阵不唯一。

### 12.1 一个典型的秩亏场景

若机器人始终只做直线前进，每次都近似为：

```text
odom = [某个正数, 0, 0]ᵀ
```

那么数据只能反映“前进量”相关的参数，无法充分区分：

```text
横向位移相关的参数
角度变化相关的参数
平移与转动耦合的参数
```

即使求解器给出一个数值结果，也只是很多可能解中的一个最小范数解，不能认为它是可靠的物理标定结果。

因此代码拒绝秩亏数据：

```cpp
if(decomposition.rank() < 9)
{
    throw std::runtime_error(...);
}
```

### 12.2 如何获得更好的观测数据

采样过程应覆盖不同类型的运动：

```text
直线前进
后退
左转
右转
弧线运动
不同转弯半径
不同速度下的运动
```

目标是让 `[ox, oy, oθ]` 在不同样本中具有足够变化，从而提高可观测性和数值稳定性。

## 13. 与路径校正的完整关系

对每一组有效观测：

```text
odom_increment ──> Add_Data() ──> A 的 3 行
scan_increment ──> Add_Data() ──> b 的 3 个元素
```

积累数据后：

```text
A、b ──> Solve() ──> x ──> M
```

标定完成后，对保存的每一帧里程计增量：

```text
odom_inc ──> M · odom_inc ──> correct_inc
```

再按照当前校正后的朝向，把局部增量积分成校正后的全局路径：

```text
calib_path
```

整个数据链为：

```text
TF(odom -> base_link)
          │
          ▼
cal_delta_distance()
          │
          ├──> odom_increment ──────────┐
          │                              │
激光相邻帧 PI-ICP                         ▼
          │                         Add_Data()
          ▼                              │
scan_increment ──────────────────────────┘
                                         │
                                         ▼
                                      A x ≈ b
                                         │
                                         ▼
                                      Solve()
                                         │
                                         ▼
                            correct_matrix M
                                         │
                                         ▼
                         M · odom_increment
                                         │
                                         ▼
                           /calib_path_pub_
```

## 14. 最容易混淆的几个点

### 14.1 `b` 不是偏置项

在一些机器学习或线性模型中，常写：

```text
y = Wx + b
```

其中 `b` 表示偏置（bias）。

但本作业的：

```text
A x = b
```

里面的 `b` **不是偏置项**，而是方程右侧的已知观测值，即激光匹配结果。

### 14.2 `x` 不是机器人横坐标

此处 `x` 是长度为 9 的参数向量，而不是机器人位姿中的 `x` 坐标。

### 14.3 `A` 不是一个固定数字矩阵

`A` 的列布局规则固定，但里面的数据来自不断到来的 `odom` 增量，因此每收一组样本，`A` 就多填入三行。

### 14.4 `scan = M·odom` 是线性近似模型

真实轮式里程计误差可能更复杂，不一定能被一个固定 `3×3` 矩阵完全描述。此作业的重点是学习如何：

```text
建立线性模型
构造超定方程组
使用最小二乘求解
检查数据是否可观测
```

---

## 15. 一句话总结

```text
A：由大量 odom 相对增量构造的已知观测矩阵；
x：待求的 3×3 校正矩阵 M 展开后的 9 个参数；
b：对应的激光 PI-ICP 相对位姿观测。

最小二乘求解 min ||Ax-b||²，得到使“校正后里程计增量”整体最接近“激光匹配增量”的校正矩阵 M。
```
