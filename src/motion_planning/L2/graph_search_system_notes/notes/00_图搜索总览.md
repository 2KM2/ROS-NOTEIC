# 00 图搜索总览

## 1. 什么是图搜索

图搜索可以理解成“走迷宫”。

你有：

- 起点 `Start`
- 目标 `Goal`
- 很多状态 / 节点 `Node`
- 节点之间有边 `Edge`

例如：

```text
        A
      /   \
     B     C
    / \     \
   D   E     F
```

如果从 `A` 出发，目标是 `F`，搜索算法要做的事情就是：

> 决定先看哪个节点，再看哪个节点，最终找到 F。

---

## 2. 通用搜索框架

所有经典搜索算法都可以套入这个框架：

```text
建立 Container
把起点加入 Container

while Container 不为空:

    根据某种规则取出一个节点 current

    Visit current

    如果 current 是目标:
        搜索成功

    Expansion:
        找到 current 的所有邻居

    Discover:
        找到尚未处理过的邻居

    Push:
        把这些邻居加入 Container
```

---

## 3. 四个最重要的词

### Visit

真正处理这个节点。

### Expansion

把当前节点的邻居找出来。

### Discover

第一次发现某个新节点。

### Container

保存“已经发现、以后还要处理”的节点。

---

## 4. 为什么不同算法看起来很像

因为：

```text
BFS
DFS
UCS
Greedy
A*
```

本质上都在重复：

```text
取一个节点
→ 访问
→ 找邻居
→ 加入容器
```

区别主要在于：

> 从 Container 里先拿谁。

---

## 5. 五种算法一句话理解

### BFS

```text
谁先进去，谁先出来
```

### DFS

```text
谁最后进去，谁先出来
```

### UCS

```text
谁从起点走到这里最便宜，就先处理谁
```

### Greedy

```text
谁看起来离终点最近，就先处理谁
```

### A*

```text
已经花的钱 + 预计还要花的钱
谁的总估计最小，就先处理谁
```

---

## 6. 三个常见代价

搜索算法里常看到：

```text
g(n)
h(n)
f(n)
```

### g(n)

从起点到当前节点 `n` 已经付出的真实代价。

### h(n)

从当前节点 `n` 到目标的估计代价。

### f(n)

A* 使用：

```text
f(n) = g(n) + h(n)
```

---

## 7. visited 为什么重要

如果图里有环：

```text
A → B → C → A
```

没有 `visited` 的话可能无限循环。

因此通常需要：

```cpp
vector<bool> visited;
```

或者：

```cpp
unordered_set<int> visited;
```

## 9. 最重要的总框架

```cpp
container.push(start);

while (!container.empty())
{
    auto current = get_best_node();

    if (current == goal)
        return true;

    for (auto neighbor : graph[current])
    {
        if (should_add(neighbor))
        {
            container.push(neighbor);
        }
    }
}
```

你后面学到的五种算法，都只是对这个框架进行不同修改。
