# 06 五种搜索算法对比总结

## 1. 最核心对比

| 算法 | 选择标准 | 常见容器 | 是否使用启发函数 |
|---|---|---|---|
| BFS | 最早进入 | Queue | 否 |
| DFS | 最晚进入 | Stack | 否 |
| UCS | `g(n)` 最小 | Priority Queue | 否 |
| Greedy | `h(n)` 最小 | Priority Queue | 是 |
| A* | `g(n)+h(n)` 最小 | Priority Queue | 是 |

---

## 2. 三个函数

```text
g(n)
```

实际已经付出的路径代价。

```text
h(n)
```

当前节点到目标的估计代价。

```text
f(n)
```

节点的综合评分。

---

## 3. 五种算法统一写法

### BFS

```text
score = 进入顺序
```

### DFS

```text
score = 反向进入顺序
```

### UCS

```text
score = g(n)
```

### Greedy

```text
score = h(n)
```

### A*

```text
score = g(n) + h(n)
```

---

## 4. 最短路能力

| 算法 | 最短路情况 |
|---|---|
| BFS | 无权图/等权图可保证 |
| DFS | 不保证 |
| UCS | 非负边权通常可保证最小代价 |
| Greedy | 不保证 |
| A* | 合适 heuristic 条件下可保证 |

---

## 5. 小白版比喻

### BFS

> 一圈一圈搜。

### DFS

> 一条路先走到底。

### UCS

> 到目前为止哪条路最便宜，就走哪条。

### Greedy

> 哪条路看起来最接近终点，就走哪条。

### A*

> 已经花的钱 + 预计还要花的钱，哪个总和最小就走哪个。

---

## 6. 最容易考试的关系

```text
A* = UCS + heuristic
```

因为：

```text
A*: f(n)=g(n)+h(n)
```

如果：

```text
h(n)=0
```

则：

```text
A* = UCS
```

而 Greedy 只保留：

```text
h(n)
```

---

## 7. 学习地图

```text
Graph Search
│
├── 不使用路径权重
│   ├── BFS
│   └── DFS
│
├── 使用真实路径代价
│   └── UCS
│
└── 使用启发函数
    ├── Greedy
    └── A*
```

## 8. 最终记忆表

```text

```
