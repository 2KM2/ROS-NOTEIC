# HW2 运行说明

## 编译

```bash
# 在容器中
catkin build grid_path_searcher waypoint_generator
source devel/setup.bash
```

## 运行

### 基本启动

```bash
roslaunch grid_path_searcher demo.launch
```

### 自定义参数启动

```bash
# 修改地图大小和起点
roslaunch grid_path_searcher demo.launch \
  map_size_x:=20.0 \
  map_size_y:=20.0 \
  map_size_z:=5.0 \
  start_x:=0.0 \
  start_y:=0.0 \
  start_z:=1.0
```

## 使用方法

1. 启动后会自动打开 rviz 可视化界面
2. 在 rviz 中使用 **2D Nav Goal** 工具点击目标点
3. demo_node 会自动计算从起点到目标点的路径并显示

## 节点说明

- **demo_node**: 路径搜索节点（A* 和 JPS 算法）
- **random_complex**: 随机复杂地图生成器，生成圆柱形障碍物
- **waypoint_generator**: 航点生成器，接收 rviz 中的目标点
- **rviz**: 可视化界面

## 常见问题

### 编译错误：PCL requires C++14 or above

已修复，CMakeLists.txt 已设置 `-std=c++14`

### rviz 无法启动

检查 X11 转发配置：
```bash
# 在宿主机
xhost +local:
```

## 地图参数说明

- `map/circle_num`: 圆形障碍物数量（默认 40）
- `map/obs_num`: 障碍物数量（默认 300）
- `map/resolution`: 地图分辨率（默认 0.1m）
- `ObstacleShape/lower_rad`, `upper_rad`: 障碍物半径范围
- `ObstacleShape/lower_hei`, `upper_hei`: 障碍物高度范围
