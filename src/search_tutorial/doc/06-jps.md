# JPS：不改变最优路径，只跳过对称节点

## 1. 核心目标

空旷 8 邻域栅格里存在大量代价相同的走法。A* 仍会把许多中间格放进 OPEN，因为它不知道
这些选择只是“先横走还是后横走”的对称排列。

Jump Point Search（JPS）不改变代价函数和启发函数，只改变邻居生成方式：沿一个方向连续
前进，普通中间格不入 OPEN，直到遇到终点、强迫邻居，或对角扫描发现水平/垂直跳点。

```text
JPS = A* + 在线识别栅格对称性 + 把一段直线/对角线压成一条边
```

## 2. 自然邻居与强迫邻居

- 自然邻居：继续当前方向时仍可能属于最优路径的方向。
- 强迫邻居：障碍破坏了对称性，迫使路径在这里保留一个转向选择。

例如向右走时，上方被障碍挡住、右上方却可走，右上就是强迫邻居。当前格必须成为跳点，
否则剪枝会错过绕障碍的最优路径。

## 3. `jump()` 的递归规则

`jump(x,y,dx,dy)` 每次前进一步：

1. 撞墙或越界：当前方向没有跳点。
2. 到终点：终点是跳点。
3. 存在强迫邻居：当前格是跳点。
4. 对角移动时，若水平或垂直子扫描找到跳点：当前格也是跳点。
5. 否则继续沿同一方向跳。

父链只保存跳点。`pathIds()` 再把相邻跳点间的线段展开成逐格路径，方便机器人执行和与
Dijkstra 对比。

## 4. 为什么仍然最优

JPS 删除的是可交换的对称排列。例如空旷区域里的“右、右、上”和“右、上、右”代价相同。
障碍让交换不再成立时就会产生强迫邻居并停止跳跃。因此最优路径可以规范化为一条经过跳点的
等价路径，再由 A* 的 `g+h` 顺序找到。

自检在随机地图上把 JPS 与现有 Dijkstra 逐例比较：可达性必须相同，成功时代价误差小于
`1e-6`。

## 5. 运动模型限制

本实现采用经典教材中常见的 JPS 模型：

- 8 邻域；
- 直边代价 `1`，斜边代价 `sqrt(2)`；
- 对角目标格空闲即可移动，也就是允许穿角。

禁止穿角的 JPS 需要另一套邻居剪枝和强迫邻居规则，不是改一个布尔值就够。为了避免提供一个
看似可配、实际可能漏路的接口，本类不暴露该开关。需要禁止穿角时可使用 Dijkstra、A* 或
D* Lite；若扩展 JPS，应成套修改 `prunedDirections()` 和 `hasForcedNeighbor()` 并重新跑随机
图交叉验证。

## 6. 代码与运行

| 概念 | 代码 |
|---|---|
| A* 主循环 | `JumpPointSearch::search()` |
| 邻居剪枝 | `prunedDirections()` |
| 跳跃扫描 | `jump()` |
| 强迫邻居 | `hasForcedNeighbor()` |
| 跳点父链 | `jumpPointIds()` |
| 展开逐格路径 | `pathIds()` |

```bash
rosrun search_tutorial advanced_search_demo
rosrun search_tutorial advanced_search_selfcheck 300
```

演示图中的 `J` 是父链中的跳点，`*` 是展开后的路径格。空旷规则地图通常收益最大；障碍密集、
通道狭窄时跳跃很快被打断，JPS 会逐渐接近普通 A* 的工作量。
